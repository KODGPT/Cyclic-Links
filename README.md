# Cyclic Links

Chrome-расширение, которое **подсвечивает ссылки, ведущие на текущую страницу** (само-ссылки / циклические ссылки / self-referencing links).

Такие ссылки часто остаются по ошибке после копи-паста, при генерации меню, пагинации, хлебных крошек и т.д. Они раздражают пользователей (клик → ничего не происходит) и немного портят UX.

Расширение помогает быстро их находить и визуально выделять.

## Как выглядит подсветка

- Красная пульсирующая рамка  
- Лёгкое увеличение при анимации  
- Ярлык 🔥 в правом верхнем углу ссылки  
- Очень высокий z-index, чтобы не перекрывался другими элементами

## Основные возможности

- Автоматическое сканирование страницы при загрузке и при изменении DOM  
- Поддержка динамического контента (MutationObserver)  
- Отслеживание изменений URL через history.pushState / replaceState / popstate  
- Вкл/выкл в один клик через popup  
- Счётчик найденных циклических ссылок (в badge и в интерфейсе — опционально)  
- Минимальные права: только `storage`, `activeTab`, `scripting`  
- Полностью безопасный код: ошибки глотаются, ничего не ломается

## Установка (режим разработчика)

1. Скачай или клонируй репозиторий  
2. Открой `chrome://extensions/`  
3. Включи **«Режим разработчика»**  
4. Нажми **«Загрузить распакованное расширение»**  
5. Выбери папку с проектом

Готово — иконка появится в панели расширений.
